Crest Commercial is a bespoke frontend application designed for a luxury commercial property brokerage operating within the SADC region. 

This project demonstrates high-end UI/UX principles, complex responsive layouts, and robust React state management without relying on heavy frontend frameworks.

## 🌟 Key Features

*   **"Silent Authority" UI:** A minimalist, highly editorial aesthetic utilizing custom 4:3 cinematic image ratios and precise typography.
*   **Advanced State Management:** Real-time, multi-parameter filtering of mock property data (Location, Property Type) without page reloads.
*   **Flawless Responsiveness:** Complex z-index handling and overlapping CSS margin architectures that adapt perfectly from mobile to ultra-wide desktop displays.
*   **Optimized Asset Loading:** Custom dual-layer image loading hooks with blur-up transitions for a seamless, cinematic user experience.

## 🛠️ Tech Stack

*   **Core:** React 18 (Functional Components & Hooks)
*   **Styling:** Tailwind CSS (Utility-first precision)
*   **Routing:** React Router DOM v6
*   **Icons:** Lucide-React
*   **Build Tool:** Vite
